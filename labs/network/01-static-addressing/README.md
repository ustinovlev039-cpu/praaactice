# NET-01 · Статическая адресация

> Настроить адрес узла и шлюз, затем отделить ошибки локальной сети от ошибок маршрутизации.

| Формат | Исходный кейс | Основной фокус |
| :-- | :-- | :-- |
| Учебная практика PT Start | `811` | Сети |

## Стенд и схема

Debian и сетевые ВМ по схеме кейса. Адреса и имена интерфейсов в командах — примеры, их нужно сверить с фактической схемой.

```mermaid
flowchart LR
    n0["Debian"]
    n1["MikroTik / шлюз"]
    n2["Учебная подсеть"]
    n0 --> n1 --> n2
    classDef default fill:#10283b,stroke:#36d9b2,color:#ffffff,stroke-width:2px
```

Схема показывает логику лабораторной. Для точного повторения исходного кейса используются его адресный план, образы и версии компонентов. Подготовка среды описана в [руководстве по стендам](../../../docs/lab-environment.md).

## Ход работы

1. Создать Internal Network в VirtualBox и подключить Debian и MikroTik.
2. Задать адреса из одной подсети, указать шлюз Debian; сверить интерфейсы до изменения конфигурации.
3. Проверить адрес, маршрут по умолчанию и доступность шлюза.
4. Сохранить конфигурацию и проверить её после перезапуска сетевой службы.

## Команды и контрольные проверки

```bash
ip -br address
ip route
ping -c 3 192.168.1.1
ip neigh
```

Это команды проверки или пример исправления, а не сохранённый вывод с выполненного стенда. Полный набор действий зависит от подготовленного образа и версии ПО.

## Как подтвердить результат

- Таблица адресации Debian и MikroTik.
- Вывод адресов, маршрутов и проверки связи до и после настройки.

Для фиксации фактического прогона используется [шаблон отчёта](../../../templates/run-report.md).

## Что важно для SOC

Неожиданная смена адреса шлюза или его MAC требует проверки конфигурации и ARP-таблицы. Отсутствие ping само по себе не доказывает недоступность сервиса.

## Защита и повторная проверка

Фиксировать адресный план, избегать дубликатов IP, ограничивать административный доступ к маршрутизатору.

После изменения конфигурации повторяется исходная проверка: нужно подтвердить устранение причины и сохранение штатной функции, а не только исчезновение ошибки в интерфейсе.
