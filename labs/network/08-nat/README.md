# NET-08 · NAT и публикация сервисов

> Разобрать изменение адресов при SNAT и DNAT и связать соединение с исходным клиентом.

| Формат | Исходный кейс | Основной фокус |
| :-- | :-- | :-- |
| Учебная практика PT Start | `749` | Сети |

## Стенд и схема

Debian и сетевые ВМ по схеме кейса. Адреса и имена интерфейсов в командах — примеры, их нужно сверить с фактической схемой.

```mermaid
flowchart LR
    n0["Внутренний клиент"]
    n1["MikroTik / NAT"]
    n2["Учебный сервис"]
    n0 --> n1 --> n2
    classDef default fill:#10283b,stroke:#36d9b2,color:#ffffff,stroke-width:2px
```

Схема показывает логику лабораторной. Для точного повторения исходного кейса используются его адресный план, образы и версии компонентов. Подготовка среды описана в [руководстве по стендам](../../../docs/lab-environment.md).

## Ход работы

1. Подготовить внутренний клиент, маршрутизатор и учебный сервис.
2. Настроить source NAT для исходящего соединения.
3. Создать ограниченный dst-nat для одного тестового сервиса.
4. Сравнить адреса на обеих сторонах маршрутизатора и счётчики правил; проверить разрешение в forward-chain.

## Команды и контрольные проверки

```routeros
/ip firewall nat print stats
/ip firewall filter print stats
/ip firewall connection print
```

Это команды проверки или пример исправления, а не сохранённый вывод с выполненного стенда. Полный набор действий зависит от подготовленного образа и версии ПО.

## Как подтвердить результат

- Таблица исходных и преобразованных адресов/портов.
- Счётчики сработавших правил и результат доступа к сервису.

Для фиксации фактического прогона используется [шаблон отчёта](../../../templates/run-report.md).

## Что важно для SOC

Для атрибуции за NAT нужны время, исходный порт и таблица трансляций. NAT не заменяет политику межсетевого экрана.

## Защита и повторная проверка

Публиковать только нужные сервисы, ограничивать источники и отдельно проверять firewall.

После изменения конфигурации повторяется исходная проверка: нужно подтвердить устранение причины и сохранение штатной функции, а не только исчезновение ошибки в интерфейсе.
